# 班级智能管理系统使用说明

## 一、系统简介

班级智能管理系统是一款基于Python+PyQt5+Deepseek API开发的教育管理工具，旨在帮助教师实现学生信息管理、个性化教育分析和班级整体管理。系统集成了人工智能技术，能够为每位学生提供因材施教的分析和建议。

## 二、系统功能

### 1. 学生管理
- **添加学生**：录入学生基本信息，包括姓名、性别、年龄、班级、学习风格等
- **编辑学生**：修改已存在学生的信息
- **删除学生**：移除不需要的学生记录
- **查看详情**：查看学生的详细信息

### 2. 因材施教
- **学生分析**：基于学生数据，提供个性化的教育分析
- **学习计划生成**：为学生生成定制化的学习计划
- **流式输出**：实时展示AI分析过程，提升用户体验

### 3. 思考过程
- **问题输入**：输入任意教育相关问题
- **思考过程展示**：查看AI模型的详细思考过程
- **逻辑分析**：了解AI如何分析和解决问题

### 4. 班级分析
- **班级选择**：选择要分析的班级
- **整体分析**：分析班级的整体情况和特点
- **教学建议**：提供针对班级的教学建议和管理策略

## 三、安装与配置

### 1. 环境要求
- Python 3.7+
- PyQt5 5.15+
- requests 2.32+
- pandas 3.0+
- numpy 2.4+
- pyqtgraph 0.14+

### 2. 安装步骤
1. **克隆项目**：将项目文件复制到本地目录
2. **安装依赖**：在项目目录下运行
   ```bash
   pip install -r requirements.txt
   ```
3. **配置API密钥**：
   - 打开 `ui/main_window.py` 文件
   - 找到第48行，将 `YOUR_DEEPSEEK_API_KEY` 替换为实际的Deepseek API密钥
   - 保存文件

### 3. 启动系统
在项目目录下运行：
```bash
python main.py
```

## 四、使用指南

### 1. 学生管理模块
1. **添加学生**：
   - 点击"添加学生"按钮
   - 填写学生信息表单
   - 点击"确定"保存
2. **编辑学生**：
   - 在表格中选择要编辑的学生
   - 点击"编辑学生"按钮
   - 修改学生信息
   - 点击"确定"保存
3. **删除学生**：
   - 在表格中选择要删除的学生
   - 点击"删除学生"按钮
   - 确认删除操作
4. **查看详情**：
   - 点击学生行对应的"详情"按钮
   - 在弹出窗口中查看学生详细信息

### 2. 因材施教模块
1. **选择学生**：
   - 在左侧学生列表中选择要分析的学生
2. **分析学生**：
   - 点击"分析学生"按钮
   - 等待AI分析完成（流式输出）
   - 查看分析结果
3. **生成学习计划**：
   - 选择学生后点击"生成学习计划"按钮
   - 等待学习计划生成
   - 查看详细的学习计划

### 3. 思考过程模块
1. **输入问题**：
   - 在"问题输入"文本框中输入教育相关问题
2. **生成思考过程**：
   - 点击"生成思考过程"按钮
   - 查看AI的详细思考过程
3. **清空内容**：
   - 点击"清空"按钮重置输入和输出

### 4. 班级分析模块
1. **选择班级**：
   - 在下拉菜单中选择要分析的班级
2. **分析班级**：
   - 点击"分析班级"按钮
   - 等待班级分析完成
   - 查看班级分析结果和建议

## 五、数据管理

### 1. 数据存储
- 学生数据存储在 `students_data.csv` 文件中
- 系统会自动创建和管理数据文件
- 数据包括学生基本信息、成绩、兴趣爱好和学习风格

### 2. 数据备份
- 建议定期备份 `students_data.csv` 文件
- 可以将文件复制到安全位置作为备份

## 六、常见问题与解决方案

### 1. API调用失败
- **问题**：分析功能无法使用，提示API错误
- **解决方法**：检查API密钥是否正确，确保网络连接正常

### 2. 数据加载失败
- **问题**：学生数据无法加载
- **解决方法**：检查 `students_data.csv` 文件是否存在且格式正确

### 3. 界面响应缓慢
- **问题**：系统操作响应缓慢
- **解决方法**：关闭其他占用系统资源的程序，确保电脑性能充足

### 4. 分析结果不完整
- **问题**：AI分析结果不完整或被截断
- **解决方法**：检查网络连接，确保API调用过程中网络稳定
